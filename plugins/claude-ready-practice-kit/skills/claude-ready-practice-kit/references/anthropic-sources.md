# What Anthropic says about Projects, connectors and sharing

Checked: November 19, 2026, on Anthropic's own help center only. Most articles show "Updated this week" instead of a date. If the owner's screen looks different, trust the screen and the live article.

## Projects
Sources: [What are projects?](https://support.claude.com/en/articles/9517075-what-are-projects), [How can I create and manage projects?](https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects)
- A Project is a workspace with its own chats, files (called project knowledge) and instructions.
- Projects are on all plans. Free accounts can make up to five.
- To create one: Projects in the left sidebar (or claude.ai/projects), then "+ New Project," then a name and description. Claude doesn't read the name or description.
- Files go in the knowledge area on the right side of the Project page, with the + button. Claude uses them in every chat in that Project.
- Instructions: "Set project instructions," write them, then "Save instructions." They apply to every chat in the Project.
- Chats in the same Project don't see each other unless the information is added to the Project's files.
- On paid plans, Claude switches on RAG mode to hold more files when a Project gets large.
- Team and Enterprise can share a Project with "Can view" or "Can edit." Use "Share project" next to the name.
- A new version of Projects is rolling out to some Pro, Max and Ultra users. Nothing is lost in the move.

## Uploads
Source: [Upload files to Claude](https://support.claude.com/en/articles/8241126-upload-files-to-claude)
- PDF, DOCX, CSV, TXT, XLSX and other text files. Project files up to 30 MB each. The total has to fit in what Claude can read at once.
- Excel files need code execution and file creation turned on.

## Connectors
Sources: [Use connectors to extend Claude's capabilities](https://support.claude.com/en/articles/11176164-use-connectors-to-extend-claude-s-capabilities), [Use Google Workspace connectors](https://support.claude.com/en/articles/10166901-use-google-workspace-connectors), [Connect to Microsoft 365](https://support.claude.com/en/articles/15183774-connect-to-microsoft-365)
- Connectors let Claude reach your apps with your own permissions in that app.
- Turn one on in Customize, then Connectors, or the + in a chat, then Connectors. Browse the directory with the + beside Connectors.
- Connectors aren't on in every chat. Turn on the ones you want per chat.
- Team and Enterprise: an Owner enables a connector for the organization, then each person signs in.
- Google Drive, Gmail and Google Calendar are available to all users. The Drive connector reads Sheets, Slides, PDFs and Office files, text only.
- Microsoft 365 is available on all plans. Work accounts reach SharePoint, OneDrive, Outlook, Calendar and Teams, read-only unless an admin turns on write tools. Team and Enterprise need the Claude Owner and a Microsoft admin to approve it.
- Anthropic: connect only services you trust and need, and disconnect ones you no longer use. Connected services process data under their own terms.

## Skills
Source: [What are skills?](https://support.claude.com/en/articles/12512176-what-are-skills)
- Skills load only when a task calls for them. Project files are always loaded in that Project.

## HIPAA
Sources: [HIPAA-ready Enterprise plans](https://support.claude.com/en/articles/13296973-hipaa-ready-enterprise-plans), [Business Associate Agreements (BAA) for commercial customers](https://privacy.claude.com/en/articles/8114513-business-associate-agreements-baa-for-commercial-customers)
- Only Claude Enterprise can enable HIPAA and a BAA. Team, Free, Pro, Max and Ultra can't.
- Under the Enterprise BAA, Anthropic lists chat and Projects as covered, and connectors, skills and plugins, and shared or published artifacts as not covered.
- Anthropic: don't process patient information through any feature that isn't covered.

## Not found on Anthropic's pages

- Which accounting or design tools are in the Connectors directory today. Tell the owner to check the directory.
