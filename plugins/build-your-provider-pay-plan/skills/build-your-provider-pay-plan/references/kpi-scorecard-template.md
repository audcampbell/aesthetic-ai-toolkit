# Provider KPI scorecard

One page per provider per month. The owner sets every goal. Points convert to flat dollars, never a percentage of sales.

## The scorecard

| KPI | This month | Goal (1 point) | Stretch (2 points) | Points |
|---|---|---|---|---|
| Rebooking rate | | | | |
| Consult conversion rate | | | | |
| Memberships sold | | | | |
| Average ticket | | | | |
| Retail sales | | | | |
| 5-star reviews naming the provider | | | | |
| **Total points** | | | | |

**Point value:** $____ a point. **Monthly cap:** ____ points.
**Bonus this month:** total points × point value = $____

## Example (fictional injector)

| KPI | This month | Goal | Stretch | Points |
|---|---|---|---|---|
| Rebooking rate | 72% | 70% | 80% | 1 |
| Consult conversion rate | 62% | 55% | 60% | 2 |
| Memberships sold | 6 | 4 | 6 | 2 |
| Average ticket | $460 | $450 | $500 | 1 |
| Retail sales | $1,200 | $1,500 | $2,500 | 0 |
| 5-star reviews naming them | 4 | 3 | 5 | 1 |
| **Total** | | | | **7** |

At $100 a point, the bonus is $700.

## Rules that keep it fair

- Use the same report, same date range, every month.
- Share the scorecard with the provider every month, not only at review time.
- Set goals from real numbers. For a new hire, wait 60 days.
- Review goals every 6 months. Raise them only with the provider, and explain why.
- If the practice changes something the provider can't control (prices, the schedule, a device going down), adjust that month's goals.
